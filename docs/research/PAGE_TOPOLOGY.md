# Third Code ERP public landing topology

1. Floating navigation — static, transparent-to-solid visual treatment.
2. Attention hero — asymmetric editorial composition with original construction image.
3. Proof rail — continuously moving operational vocabulary; decorative only.
4. Interest bento — 12-column, 24-cell dense grid with AI Brain, operations, compliance.
5. Horizontal capability accordion — hover/focus/click expansion.
6. Desire narrative — scroll-linked image scaling and stacked workflow cards.
7. Testimonial carousel — manual controls; no autoplay.
8. Action CTA — high-contrast consultation and workspace entry.
9. Footer — product, trust, and company links.

All page sections stay in document flow. No interaction is required to reveal core
copy. JavaScript adds motion and progressive disclosure only.
