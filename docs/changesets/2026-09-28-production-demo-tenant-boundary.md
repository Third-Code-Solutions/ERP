# Production demo E2E tenant boundary

The protected production workflow now fixes `E2E_DEMO_TENANT_SLUG` to `buildops-e2e` and runs a read-only preflight before authenticated browser tests. It resolves that slug to a tenant ID, checks all eleven fixed demo role profiles are active in that tenant, and requires the configured active E2E project to belong to the same tenant. The preflight's JSON report is rejected if the test was skipped. The magic-link helper rechecks each profile and its active status before issuing a test session, and the role and schedule matrices recheck project ownership before their selected runs.
